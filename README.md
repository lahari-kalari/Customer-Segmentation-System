
# Customer Segmentation System

## Project Description
This project uses Machine Learning to group customers based on their annual income and spending scores. It helps demonstrate how businesses can identify different customer groups.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Algorithm
K-Means Clustering

## Features
- Loads customer data from a CSV file.
- Groups customers into four clusters.
- Predicts the cluster for a new customer.
- Displays customer groups using a graph.

## Dataset
The project uses a small illustrative dataset containing customer IDs, ages, annual incomes, and spending scores.

## How to Run
1. Install Python.
2. Install the required libraries:
   `python -m pip install pandas scikit-learn matplotlib`
3. Run the program:
   `python main.py`
4. Enter the annual income and spending score when prompted.

## Disclaimer
This is an educational project using illustrative sample data. The results are intended for demonstration and should not be used for real business decisions.
